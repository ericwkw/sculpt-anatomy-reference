# photos-raw

Drop capture photos here. Everything in this folder except this file is gitignored, and
the folder sits outside `public/`, so it is never committed, built into `dist/`, or
deployed to GitHub Pages.

One subfolder per subject, e.g. `photos-raw/maquette-01/`.

## Capturing for photogrammetry

- 30-100 photos per subject, one object, fixed shape (nothing moves between shots).
- Walk around it in steps of 10-15 degrees; do it at 2-3 heights, plus a few from above.
- Every shot overlaps the previous one by about 70%.
- Soft, even light. Avoid harsh shadows and glare; light should not change between shots.
- Sharp focus, same zoom, no digital zoom. HEIC or JPEG both fine.
- Textured or matte surface, on a background that differs from the object.
- Keep the original files; do not crop or filter.
